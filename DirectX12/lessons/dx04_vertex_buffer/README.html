先读哪些代码

Vertex Buffer View / Upload Heap

本目录 main.cpp 选择本课的执行路径。完整 API 实现在 common/dx12_course.hpp（相对路线根目录），数学和网格在仓库 shared/scene.hpp。每课都是独立程序；共享代码避免把相同资源生命周期错误复制十遍，也会为后续课预先初始化部分公共状态。首次阅读只沿本课列出的调用路径展开。

原理和实现

D3D12_VERTEX_BUFFER_VIEW 包含 GPU 地址、总字节数和 stride，不是绑定某个 C++ 数组指针。本教学几何先使用 upload heap 直接读取，易于观察；大静态网格应 staging 到 default heap 并转换 VERTEX_AND_CONSTANT_BUFFER 状态。

本课使用与 Vulkan 相同的几何和验证目标，比较资源绑定与同步的不同表达。CPU 创建的数据、GPU 资源和用于访问它的 view/descriptor 是不同层次；用调试层与抓帧工具分别核对接口约定和实际内容。命令异步执行，示例显式等待 fence 后才重用单份上传资源与 command allocator。

HLSL 使用 column_major 与 mul(M,v)，保持与共享 GLM 数据相同的内存和乘法约定。调整窗口大小时必须更新尺寸相关的目标与投影；map、创建视图或改变 CPU 变量都不会替代已经提交给 GPU 的工作。

修改练习

改变 Vertex 的属性顺序，并同步修改 input layout；把静态几何转到 default heap。

修改 shader 后重新构建，再运行。Vulkan GLSL 会被编译并复制到 exe 旁的 shaders；DX12 的 HLSL 副本也随构建更新，运行时再编译。应修改源目录而不是运行副本。

VBV 的 BufferLocation 是 CPU 地址吗？

参考：不是，它是资源的 GPU 虚拟地址。

本课的真实源码切片

来自 DirectX12/common/dx12_course.hpp，第 246—275 行；这是现有实现的局部摘录，末尾可能处于函数中间，不是可单独编译的完整程序。

    DxScene(DxDevice& context, int lesson) : c(context), mode(lesson), mesh(geometry(mode)) {
        if (mode >= 4) {
            UINT size = UINT(mesh.vertices.size() * sizeof(Vertex));
            vertices = c.buffer(size, D3D12_HEAP_TYPE_UPLOAD, D3D12_RESOURCE_STATE_GENERIC_READ);
            void* mapped;
            D3D12_RANGE empty{0, 0};
            dxCheck(vertices->Map(0, &empty, &mapped));
            std::memcpy(mapped, mesh.vertices.data(), size);
            vertices->Unmap(0, nullptr);
            vb = {vertices->GetGPUVirtualAddress(), size, sizeof(Vertex)};
            if (!mesh.indices.empty()) {
                UINT bytes = UINT(mesh.indices.size() * 4);
                indices =
                    c.buffer(bytes, D3D12_HEAP_TYPE_UPLOAD, D3D12_RESOURCE_STATE_GENERIC_READ);
                dxCheck(indices->Map(0, &empty, &mapped));
                std::memcpy(mapped, mesh.indices.data(), bytes);
                indices->Unmap(0, nullptr);
                ib = {indices->GetGPUVirtualAddress(), bytes, DXGI_FORMAT_R32_UINT};
            }
        }

        // CBV GPU 地址要求 256 字节对齐，因此给 64 字节的帧矩阵预留 256 字节。
        uniform = c.buffer(256, D3D12_HEAP_TYPE_UPLOAD, D3D12_RESOURCE_STATE_GENERIC_READ);
        D3D12_HEAP_PROPERTIES hp{};
        hp.Type = D3D12_HEAP_TYPE_DEFAULT;
        D3D12_RESOURCE_DESC image{};
        image.Dimension = D3D12_RESOURCE_DIMENSION_TEXTURE2D;
        image.Width = image.Height = 64;
        image.DepthOrArraySize = 1;
        image.MipLevels = 1;

VBV 正确是否保证 NORMAL 语义正确？

参考推导：不能。还要核对 input layout 的 format/offset 和 HLSL 输入声明，地址正确不等于解释正确。

在一次实验中只改一个因素，记录预测、实际画面/日志和原因。检查已有 smoke 是否仍通过；图形调试器里再核对本次 draw 的实际输入/输出，不能仅凭进程正常退出下结论。
