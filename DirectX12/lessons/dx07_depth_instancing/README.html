先读哪些代码

DSV / Depth State / InstanceID

本目录 main.cpp 选择本课的执行路径。完整 API 实现在 common/dx12_course.hpp（相对路线根目录），数学和网格在仓库 shared/scene.hpp。每课都是独立程序；共享代码避免把相同资源生命周期错误复制十遍，也会为后续课预先初始化部分公共状态。首次阅读只沿本课列出的调用路径展开。

原理和实现

深度图 default heap、D32 格式、DEPTH_WRITE 状态；DSV 绑定与 PSO 的 depth format/test/func 必须一致。实例位置由 SV_InstanceID 产生。一个命令列表使用完整的当前状态，不继承另一个列表里的资源绑定。

本课使用与 Vulkan 相同的几何和验证目标，比较资源绑定与同步的不同表达。CPU 创建的数据、GPU 资源和用于访问它的 view/descriptor 是不同层次；用调试层与抓帧工具分别核对接口约定和实际内容。命令异步执行，示例显式等待 fence 后才重用单份上传资源与 command allocator。

HLSL 使用 column_major 与 mul(M,v)，保持与共享 GLM 数据相同的内存和乘法约定。调整窗口大小时必须更新尺寸相关的目标与投影；map、创建视图或改变 CPU 变量都不会替代已经提交给 GPU 的工作。

验证和调试

运行 dx07_depth_instancing.exe --smoke 执行四帧（或设备/计算检查）并退出；颜色课会从 GPU 读回 PPM，计算课验证 256 个数。参见仓库 调试指南。这些基础例子按帧串行等待，重点是可追踪的生命周期；多帧重叠不能仅删除 wait，需要同时改成帧资源环。

本课的真实源码切片

来自 DirectX12/common/dx12_course.hpp，第 525—554 行；这是现有实现的局部摘录，末尾可能处于函数中间，不是可单独编译的完整程序。

    void resize(int w, int h) {
        if (width == w && height == h)
            return;
        c.wait();
        for (auto& image : colors)
            image.Reset();
        depth.Reset();
        offscreen.Reset();
        multisample.Reset();
        dxCheck(swap->ResizeBuffers(2, UINT(w), UINT(h), DXGI_FORMAT_R8G8B8A8_UNORM, 0));
        width = w;
        height = h;
        for (UINT i = 0; i < 2; ++i) {
            dxCheck(swap->GetBuffer(i, IID_PPV_ARGS(&colors[i])));
            c.device->CreateRenderTargetView(colors[i].Get(), nullptr, rtv(i));
        }
        D3D12_HEAP_PROPERTIES heap{};
        heap.Type = D3D12_HEAP_TYPE_DEFAULT;
        D3D12_RESOURCE_DESC desc{};
        desc.Dimension = D3D12_RESOURCE_DIMENSION_TEXTURE2D;
        desc.Width = UINT64(w);
        desc.Height = UINT(h);
        desc.DepthOrArraySize = 1;
        desc.MipLevels = 1;
        desc.Format = DXGI_FORMAT_D32_FLOAT;
        desc.SampleDesc.Count = options.samples;
        desc.Flags = D3D12_RESOURCE_FLAG_ALLOW_DEPTH_STENCIL;
        D3D12_CLEAR_VALUE clear{};
        clear.Format = desc.Format;
        clear.DepthStencil.Depth = 1;
