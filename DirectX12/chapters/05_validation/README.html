本课目标与先修

学习目标：解释“验证层、调试队列与诊断证据”解决的问题，找到实际对象和参数，运行对应实验并用数据/画面证明。先完成前一课，并能说明它交付的对象与完成条件；本课在该依赖上增加新契约。

为什么需要这一层

API 验证负责检查使用约束，应用断言负责检查业务结果。画面正常但有同步错误仍不算通过；验证零错误也不证明法线空间或材质公式正确。本课用合法的信息消息验证诊断链路，不以故意破坏 API 当常规验收。
