本课目标与先修

学习目标：解释“图形管线的组合与兼容性”解决的问题，找到实际对象和参数，运行对应实验并用数据/画面证明。先完成前一课，并能说明它交付的对象与完成条件；本课在该依赖上增加新契约。

为什么需要这一层

管线将可编程阶段与固定功能状态组合，使一次 draw 有明确解释。不要把“shader 编译成功”当成整个管线有效；输入布局、输出目标、深度和写掩码都可能改变最终结果。

DirectX 12 的对象、参数与执行推导

PSO 包含 VS/PS、input layout、raster/blend/depth、目标格式和 sample desc，root signature 提供资源接口。SV_VertexID 路径帮助先验证管线，再在顶点课增加输入资源。

对照 Vulkan 原生：相同问题的另一种分工

GraphicsPipelineCreateInfo 组合阶段、顶点输入、装配、viewport、raster、multisample、depth、blend、layout 和附件格式。dynamic state 只有声明后才能由相应命令设置。当前三角形用 gl_VertexIndex，故意不引入 VBO。

关键实现：从当前源码定位

来自 DirectX12/common/dx12_course.hpp，第 397—440 行。下列是当前仓库的局部切片，可能在函数中间结束；完整上下文请打开文件，切片不作为单独可编译程序。

        D3D12_GRAPHICS_PIPELINE_STATE_DESC pso{};
        pso.pRootSignature = signature.Get();
        pso.VS = {vs->GetBufferPointer(), vs->GetBufferSize()};
        pso.PS = {ps->GetBufferPointer(), ps->GetBufferSize()};
        pso.BlendState.RenderTarget[0].RenderTargetWriteMask =
            redOnly ? D3D12_COLOR_WRITE_ENABLE_RED | D3D12_COLOR_WRITE_ENABLE_ALPHA
                    : D3D12_COLOR_WRITE_ENABLE_ALL;
        pso.SampleMask = UINT_MAX;
        pso.RasterizerState.FillMode = D3D12_FILL_MODE_SOLID;
        pso.RasterizerState.CullMode = cull;
        // 共用模型按外表面逆时针排列；明确指定正面，避免剔除后只剩内部。
        pso.RasterizerState.FrontCounterClockwise = TRUE;
        pso.RasterizerState.DepthClipEnable = TRUE;
        pso.DepthStencilState.DepthEnable = mode >= 5;
        pso.DepthStencilState.DepthWriteMask =
            mode >= 5 ? D3D12_DEPTH_WRITE_MASK_ALL : D3D12_DEPTH_WRITE_MASK_ZERO;
        pso.DepthStencilState.DepthFunc = D3D12_COMPARISON_FUNC_LESS;
        pso.DepthStencilState.StencilReadMask = pso.DepthStencilState.StencilWriteMask = 0xFF;
        if (mode >= 4)
            pso.InputLayout = {elements, 3};
        pso.PrimitiveTopologyType = D3D12_PRIMITIVE_TOPOLOGY_TYPE_TRIANGLE;
        pso.NumRenderTargets = 1;
        pso.RTVFormats[0] = DXGI_FORMAT_R8G8B8A8_UNORM;
        pso.DSVFormat = DXGI_FORMAT_D32_FLOAT;
        pso.SampleDesc.Count = samples;
        dxCheck(c.device->CreateGraphicsPipelineState(&pso, IID_PPV_ARGS(&pipeline)));
    }

参考推导与通过标准

先查 draw 是否提交，再查顶点裁剪坐标、viewport/scissor、剔除、深度与目标。固定色仍不出现时先不要研究纹理参数。

常见失败与排查顺序

动态渲染不是“动态创建所有管线状态”；附件格式和多样本配置仍须与管线兼容。

先看第一条错误和当前执行路径，再看实际数据/绑定，最后看 shader 与画面。需要 GPU 证据时抓取正常交互帧；仅四帧的 smoke 适合自动检查，不适合手动抓帧。
