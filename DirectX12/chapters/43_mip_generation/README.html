为什么需要这一层

mip 链是预先缩小的图像集合，层数通常到 1×1。资源级数、上传内容、每级状态、view 和 sampler LOD 必须一起更新。本课不仅创建多个级别，还逐 texel 读回并与 CPU 参考比较。

DirectX 12 的对象、参数与执行推导

GPU 计算使用 SRV 指前一级、UAV 指后一级，8×8 工作组平均四个 texel。每级 descriptor 与 subresource state 分开管理，最后转可采样。sRGB 材质链另用正确线性平均的 CPU 路径，未把编码值简单平均冒充正确颜色 mip。

对照 Vulkan 原生：相同问题的另一种分工

查询格式的 blit/filter 支持，上传 level 0，逐级 transition 和 linear blit，再把所有级别转成 shader-read。每次只读取已经完成的前一级，最后复制每级结果用于校验。数值参考使用线性 UNORM。

来自 DirectX12/shaders/lab.hlsl，第 47—68 行。下列是当前仓库的局部切片，可能在函数中间结束；完整上下文请打开文件，切片不作为单独可编译程序。

    float a = corner * 2.0943951;
    Vertex v;
    v.position = float3(center + float2(cos(a), sin(a)) * .028, 0);
    v.normal = float3(.25 + .7 * (particle % 7) / 6, .65, .95);
    v.uv = 0;
    vertices[i] = v;
} Texture2D<float4> mipSource : register(t0);
RWTexture2D<float4> mipOutput : register(u2);
[numthreads(8, 8, 1)] void MipMain(uint3 id : SV_DispatchThreadID) {
    uint w, h;
    mipOutput.GetDimensions(w, h);
    if (id.x >= w || id.y >= h)
        return;
    uint sw, sh;
    mipSource.GetDimensions(sw, sh);
    uint2 base = id.xy * 2;
    float4 sum = 0;
    for (uint y = 0; y < 2; ++y)
        for (uint x = 0; x < 2; ++x)
            sum += mipSource.Load(int3(min(base + uint2(x, y), uint2(sw - 1, sh - 1)), 0));
    mipOutput[id.xy] = sum * .25;
}

常见失败与排查顺序

只设置 sampler 最大 LOD 却没有生成内容，或用全资源错误 before state 覆盖各级不同状态，会产生未初始化读取。

先看第一条错误和当前执行路径，再看实际数据/绑定，最后看 shader 与画面。需要 GPU 证据时抓取正常交互帧；仅四帧的 smoke 适合自动检查，不适合手动抓帧。
