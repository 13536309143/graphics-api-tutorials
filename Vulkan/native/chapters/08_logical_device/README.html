对照 DirectX 12：相同问题的另一种分工

Device 创建后以 feature query 选择后续路径。CreateCommandQueue、CreateCommandAllocator、CreateCommandList 和 CreateFence 分别建立提交、命令存储、录制与完成计数。它们的存在不代表已经执行任何 GPU 指令。
