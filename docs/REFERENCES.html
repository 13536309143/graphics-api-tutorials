OpenGL 与窗口层

  • OGLdev 原作者窗口课：对照窗口库与 OpenGL 状态的分工。
  • GLFW window guide：查询窗口、framebuffer 尺寸与缓冲交换。
  • GLFW Vulkan guide：查询 loader、所需扩展和 surface 创建。

BootWiki 后续目录提供了从变换、光照到模型和高级效果的主题线索。本仓库依据已有 34 课重新组织对照，不把目录中出现的拾取、细分或运动模糊当作当前已实现功能。

Vulkan 细节查证

  • staging buffer：比较 CPU 可见中转与最终 GPU 资源。
  • descriptor layout / buffer：区分资源接口与内容。
  • dynamic offset：后续实现帧资源环时核对偏移与范围。
  • synchronization：按生产者和消费者选择依赖。
  • validation overview：从 VUID 返回有效用法规则。

DX12 与框架

  • Microsoft root signatures：接口、根常量和描述符表。
  • Microsoft resource barriers：legacy transition/UAV 等状态依赖。
  • Microsoft command lists：录制对象、allocator 与执行。
  • Microsoft D3D11→12 迁移说明：观察显式 CPU/GPU 生命周期管理。
  • nvpro_core2 官方仓库：以本仓库固定子模块提交为接口依据，避免直接套最新主分支示例。

如何组合使用

先从本地对照页打开真实代码，再去外部资料核对一个不理解的术语或约束。出现差异时记录版本与假设，回到本工程决定是保留当前基线还是开启迁移练习。不要为了让某个网上片段编译而同时升级 API、shader 语言和框架版本，这会让新错误难以归因。
