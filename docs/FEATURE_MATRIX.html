不能从表格直接推出的结论

Vulkan/DX12 没有 IBL 课程，不等于 API 不支持 IBL。OpenGL 当前没有 compute 课程，指这条 3.3 路线未实现，不是 OpenGL 所有版本都没有计算能力。框架提供某个 helper，也不等于课程已经接入并验收该功能。

当前场景的可比程度

Vulkan 与 DX12 复用 shared 中的几何、Frame 和 Draw；PBR shader 的直接光参数尽量保持一致。nvpro 复用 SceneVk，但输出目标和 UI 路径不同。OpenGL 保留原有独立场景和学习节奏，没有把所有例子改成与显式后端逐像素一致。

因此，同主题导航用于理解 API 差异；严格图像回归和性能对比需要先执行统一实验协议，固定场景、输入、输出与计时。已有四路线预览只证明各自画出了预期内容。

推荐补齐顺序

静态模型、mip 和 MSAA 已有真实实现；接下来可补完整材质/skin、全屏后处理、阴影与 HDR/IBL，再扩展完整多帧呈现。每次只引入一种主要变量，并保存中间纹理与验证结果。完成后更新本表、对应章节、catalog 和 smoke，而不是只在 README 中增加一个标题。
