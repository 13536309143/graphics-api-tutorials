本机部署与验证记录

日期：2026-11-03（Asia/Shanghai）。最终部署位置：OpenGL。

环境

  • CMake 4.2.1；Visual Studio 2022，MSVC 19.44.35222，x64。
  • Windows SDK 10.0.26100.0。
  • 实测显卡 NVIDIA GeForce RTX 3060；运行报告 OpenGL 3.3.0 NVIDIA 610.88。
  • GLFW 3.4、GLM 1.0.1、GLAD 2.0.8 生成的 3.3 Core 接口，全部随源码提供。

结果

在最终目录从源码重新配置、编译 Debug，13 个程序全部成功，编译日志未报告警告。随后执行：

ctest --test-dir OpenGL\build -C Debug --output-on-failure

13/13 通过，0 失败，总耗时约 7.21 秒。每个程序创建隐藏的真实 OpenGL 窗口，编译/链接 GLSL、执行四帧、检查 GL 错误；除清屏课之外，还读取颜色缓冲确认出现至少 100 个非背景像素。

示例第 09 课约 69787、第 12 课约 67407、第 13 课约 317623 个非背景像素。第 09、13 课抓图人工查看，确认有光照立方体和地面投影。截图保存在本目录 previews/。

原始测试日志在 build/Testing/Temporary/LastTest.log。复验可使用 scripts/test.ps1；这个测试需要可工作的显卡驱动与图形会话，不适合无显示环境直接运行。

验证范围

已验证本机 Windows Debug 构建和四帧渲染，检查了中文文档的本地链接。Release、Linux/macOS 构建、长时间运行、所有交互按键组合尚未逐项验证；对应说明提供的是可复现操作和源代码兼容设计，不作为这些平台的已测试承诺。
