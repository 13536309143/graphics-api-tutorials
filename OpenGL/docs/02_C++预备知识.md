# C++ 预备知识

先能写出一个控制台程序，再进入图形接口。读本工程需要下面这些概念。

1. `std::vector<float>` 是连续浮点数组；`data()` 提供首元素地址，`size()` 给元素数。GPU 上传的大小以字节为单位，需乘 sizeof(float)。
2. `GLuint` 是 OpenGL 对象句柄，不是 C++ 对象指针。glGenBuffers 返回编号，glDeleteBuffers 删除对应 GPU 资源。复制一个编号并没有复制 GPU 数据。
3. 构造函数初始化资源，析构函数释放资源，称为 RAII。本项目 Shader/Mesh/Texture 不允许复制，防止两次删除同一编号。更通用的封装可实现移动构造，但入门阶段先保持简单。
4. `const Shader&` 通过引用使用现有对象，不复制；`[&]` lambda 捕获现有局部变量的引用，第 13 课用它让两次渲染共享同一场景绘制逻辑。
5. main 的 try/catch 接住初始化、文件、shader 等错误并返回 1；局部资源在栈展开时自动释放。GPU 资源必须在 App 销毁上下文之前析构，所以 App 始终第一个声明。
6. `#include` 把声明引入翻译单元；头文件中定义小函数要 inline 或定义在类内部，避免多个 cpp 链接时重复定义。本课程每个示例是独立 target。

练习：先在 main 中打印 vector 的顶点数与字节数；再解释 `reinterpret_cast<void*>(3*sizeof(float))`。这里它表达绑定缓冲中的字节偏移，不是让 CPU 解引用地址 12。

小心整数除法。`960/640` 的结果是 1，透视宽高比应使用 float(width)/float(height)。角度建议 float，常量使用 0.5f 减少不必要的 double 转换。
