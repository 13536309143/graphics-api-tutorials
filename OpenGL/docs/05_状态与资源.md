# 状态机与资源管理

OpenGL 调用通常作用于当前状态。调试 draw 之前先回答：当前程序是谁？当前 VAO 是谁？每个 sampler 对应哪个单元，该单元绑定哪张纹理？当前 FBO、viewport、深度测试、混合、剔除状态是什么？

VAO 保存顶点属性格式、属性关联的 VBO、EBO 绑定和 divisor。GL_ARRAY_BUFFER 的当前绑定本身不属于 VAO，但 glVertexAttribPointer 会把当时的缓冲关联记录到 VAO。FBO 保存附件关联；shader program 保存 uniform 值；纹理对象保存过滤和环绕参数。

常见资源生命周期：创建句柄 → 绑定 → 上传数据/设置状态 → 绘制 → 删除。示例通过 RAII 管理，App 先构造后析构。上下文只在主线程使用，不要把 GPU 对象析构随意移动到没有 current context 的线程。

动态数据用 glBufferSubData 更新，或学习缓冲映射；本课静态几何使用 GL_STATIC_DRAW。这个参数是使用方式提示，不是强制只读。性能优化前先量 CPU/GPU 时间，不要以 glDraw 的 CPU 返回速度代替 GPU 完成时间。

透明混合扩展：启用 GL_BLEND，glBlendFunc(GL_SRC_ALPHA,GL_ONE_MINUS_SRC_ALPHA)，先画不透明物体，再对透明物体按距离从远到近排序。透明阶段通常保留深度测试并暂时 glDepthMask(GL_FALSE)，结束后恢复。不要把“关闭深度测试”当作透明问题的通用修复。

面剔除扩展：glEnable(GL_CULL_FACE)，默认剔除背面、逆时针为正面。负缩放可能翻转绕序；双面物体要明确策略。一次实验只改一个状态，才能知道结果来自哪里。
