向量、矩阵与渲染管线

向量可表示位置差、方向或颜色。长度 length(v)，归一化 normalize(v) 保持方向并令长度为 1。零向量不能归一化。dot(a,b)=|a||b|cosθ：两个单位向量的点积就是夹角余弦。cross(a,b) 产生垂直方向，交换顺序会反向。

GLSL 中 vec3*vec3 是逐分量乘法；矩阵乘向量才是线性变换。glm::mat4(1) 是单位矩阵，不是所有元素都等于 1。颜色乘标量会改变亮度，光照中 albedo*lightColor 是逐通道调制。

位置 P 的坐标链：

CPU 顶点数组 → VBO → VAO 解释属性
局部 P → M → 世界 → V → 观察 → P矩阵 → 裁剪坐标 (x,y,z,w)
裁剪 → 除以 w → NDC [-1,1] → 视口变换 → 光栅化
插值属性 → 片段 shader → 深度/模板测试与混合 → 帧缓冲

上图简化了硬件的提前深度测试等实现细节。记住“片段”并不保证成为最终像素：它还可能被裁剪、丢弃或深度测试拒绝。

透视使远物看起来小，关键在 gl_Position.w 参与除法。默认深度最终映射到 [0,1] 的深度缓冲，而 NDC z 仍是 [-1,1]。不要把阴影纹理深度直接与裁剪坐标 z 相比，必须进行除 w 和范围映射。

法线是平面的垂直方向。对位置进行非均匀缩放后，用同样矩阵乘法线无法保证垂直，因此使用逆转置。绘制前 model 必须可逆；缩放到 0 会导致 inverse 无法定义。

练习：手算 T(1,0,0)*S(2,2,2)*vec4(1,0,0,1)，结果是 (3,0,0,1)；交换 T/S 后结果是 (4,0,0,1)。用第 06 课验证。
