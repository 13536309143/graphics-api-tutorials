点击启动课程示例

双击教程根目录的 开始学习.cmd。它会启动教程自带的本地阅读器，并在浏览器打开首页。首页每个课程右侧都有“▶ 运行”，进入章节后标题下有“▶ 运行本课”。

点击后会打开独立的 OpenGL 窗口，按 Esc 退出。有相机的课程按住鼠标右键转向、W/A/S/D 移动。页面显示运行状态，运行中的课程不会重复打开。

默认选择已编译的 Debug。也可以切换 Release；尚未构建时按钮会显示“此版本尚未构建”。如需构建，使用现有 scripts/build.ps1 或 CMake build preset。运行错误时页面会提供“查看日志”，日志保存在 build/launcher-logs/。

直接双击 index.html 仍可离线阅读，但浏览器的本地文件页面不能直接启动程序；请使用“开始学习.cmd”打开带运行按钮的阅读会话。启动器仅使用本机回环地址，不需要网络连接或 Python。

阅读结束可以在页面顶部点击“关闭启动服务”。已打开的示例可继续运行，重新双击“开始学习.cmd”可恢复按钮。重复打开入口会复用已有启动服务。

启动器源码在 tools/course_browser.cpp，按钮脚本在 web/runner.js，样式在 web/runner.css。它作为 course_browser CMake 目标构建。已有章节 HTML 已接入按钮；以后生成新的 HTML 页面时也需引用对应相对路径的 runner.css 与 runner.js。
