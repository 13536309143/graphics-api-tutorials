# 进阶排错与性能

| 现象 | 优先核查 |
| --- | --- |
| 透明/粒子完全不显示 | 深度是否清过、清除时 DepthMask 是否为 true、Alpha 是否为零 |
| glTF 部件飞散 | parent*local、矩阵转置、同一节点重复变换 |
| 蒙皮拉伸爆炸 | bone ID 类型、权重和、inverseBind、meshGlobal 的逆、无权重回退 |
| 法线凹凸反转或转相机后翻转 | TBN 手性、normal 绿色方向、UV 梯度退化 |
| PBR 金属发黑 | 直接光视角、是否有 IBL、F0 基础颜色、不要用零向量求半程向量 |
| PBR 太亮/发灰 | sRGB 解码与 Gamma 次数、粗糙度通道、曝光、显示映射重复 |
| IBL 反射方向错位 | 六面朝向、up 向量、equirect 的 v 方向、reflect 入射方向符号 |
| IBL 高亮有噪点 | 样本数、源环境分辨率、预过滤 PDF/mip 策略，不能只加模糊掩盖 |
| Bloom 没效果 | HDR 值是否超过阈值、MRT draw buffers、ping-pong 最终纹理、合成空间 |
| G-buffer 没数据 | FBO/MRT 位置、alpha 背景标记、几何 pass 是否启用深度 |
| SSAO 相机移动就闪 | 观察/世界空间混用、投影除 w、深度比较方向、采样超屏 |
| MSAA FBO 不完整 | 样本数、所有附件尺寸/采样一致、设备 GL_MAX_SAMPLES |

## 按 pass 检查

为每一遍列出：输入纹理和单元、写入目标、viewport、程序、VAO、深度与模板状态、色彩空间。某一帧无 GL 错误只说明调用合法，不说明效果符合预期。本次增加了非背景/动态范围检查，并使用固定时间的开启/关闭效果抓图作差。

`program.exe --smoke --capture` 保存正常图，`--smoke --variant --capture` 在新课中模拟按住空格。图像文件写在 exe 旁。`--variant` 只用于对应有效果开关的课，不代表每个程序都有特殊分支。默认四帧时间固定为 1 秒，可稳定对比；真实运行按墙钟时间推进。

## 测性能

先分清 CPU 提交、GPU 顶点、像素着色、带宽和资源上传。GPU timer query 应延后读取结果，立即取值可能等待 GPU。不要在每帧加 glFinish 来测正常性能。glfwSwapInterval(1) 的垂直同步也会限制观察到的帧率。

本课方便阅读而做的取舍：模型每个节点重复上传静态网格；deferred 遍历全部 32 光源；SSAO 使用 32 样本；Bloom 全分辨率八遍；IBL 每次启动重算；粒子每帧更新实例缓冲。优化时依次考虑共享网格缓存、光源剔除、半分辨率 AO/Bloom、预计算资源缓存、持久数据管理，再做复杂管线。

glGetUniformLocation 每次查找也有 CPU 开销，可按程序缓存 location。资源重新链接后 location 会变，应清掉旧缓存。更高版本的 DSA、持久映射或 compute 并非本教程 3.3 基线功能，升级前同时调整上下文、GLAD、GLSL 和能力检测。
