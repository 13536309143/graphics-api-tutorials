进阶学习路线

进阶内容现在都有实际程序，从 第 14 课模型导入 开始，最后运行 第 34 课综合 PBR 展厅。

建议依赖顺序：

  • 先 14/15，学会用真实模型、节点层级和图片；16/17 理解透明与模板状态。
  • 18 看 cubemap；19/20 理解切线空间与表面细节。
  • 21/22 建立线性 HDR 后处理；23/24 实现直接光 PBR 和材质贴图。
  • 25 计算完整 split-sum IBL，不能跳过环境积分的含义。
  • 26/27 比较延迟管线和环境遮蔽；28/29 学共享数据与 MSAA。
  • 30/31/32 学图元扩展、骨骼与粒子；33 补齐点光源全向阴影。
  • 最后用 34 检查模型、材质、IBL 与 HDR 的统一约定，再选择一个效果合并进去。

模型格式兼容、PBR 公式与性能建议分别见 docs/09、10、11。还没有实现的高级主题见 后续专题与边界，不要将路线中的选题当成已经提供可执行程序。

权威参考：Khronos OpenGL、GLFW、glTF 2.0、Assimp、Filament。查看较高版本 API 文档时，始终检查本教程 3.3 Core 是否支持。
