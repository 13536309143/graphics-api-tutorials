综合练习：小型展厅

在读完第 13 课后，新建 lessons/14_gallery/main.cpp。复用现有工具，把不同知识连起来。此文件夹由你动手创建；课程提供下面的任务和验收标准。

  • 一个地面与至少五个立方体，各自有独立 model 矩阵；至少一个持续旋转。
  • 自由相机，WASD 和右键操作，按 R 回到初始姿态。
  • 棋盘纹理材质与两盏颜色不同的灯；画小立方体显示灯的位置。
  • 一盏主光的阴影，按键按下/抬起边沿切换阴影，而不是每帧重复翻转。
  • 整个场景先画到 FBO，再经过彩色/灰度后处理；改变窗口大小时同步调整附件。
  • 用实例化绘制一组展台装饰，一次 draw 提交至少 100 个。

参考组织：App 最先声明；Shader 与 Mesh/Texture/Camera 随后；ShadowMap 与 Framebuffer 管理两类目标。每帧先更新输入和时间，计算一次物体变换；渲染阴影深度；渲染展厅颜色到 FBO；最后向 framebuffer 0 画全屏后处理。每一遍都显式设置 viewport、深度状态和所需纹理。

验收：程序无 GL 错误；画面不是空白；前后遮挡正确；相机移动不改变固定光照的漫反射；窗口缩放不拉伸；阴影关闭后只有遮挡效果消失；关闭后处理后颜色恢复；退出无崩溃。给你的课补写 README，列出每个可见效果对应的 API。

思考题：如果加入透明玻璃，应在哪一遍、什么顺序绘制？如果颜色太亮，应该怎样从普通 RGB8 缓冲迁移到 HDR？如果场景有 10000 个物体，哪些成本不会被实例化解决？参考第 05、10、12 课和进阶路线。
